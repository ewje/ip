## Undoing a change

Use `undo` to reverse the most recent change made by `todo`, `deadline`, `event`, `delete`, `mark`, or `unmark`.

Example: `undo`

```text
Undid the last change.
```

Gary remembers up to 100 changes during the current application session. Enter `undo` repeatedly to reverse older
changes. Commands that fail, only display information, or leave a task unchanged are not added to the undo history.
Undo history is cleared when the application exits, and undone changes cannot be redone.

The `undo` command does not accept arguments. If there is no recorded change, Gary displays:

```text
There is no change to undo.
```
